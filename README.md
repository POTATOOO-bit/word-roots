# Word Roots 3D

กราฟ 3 มิติของรากศัพท์ภาษาอังกฤษ (ราก / prefix / suffix) และศัพท์ที่แตกออกมา
ฟองใหญ่ = รากหรือ affix (ฟ้า = ราก, ม่วง = prefix, ส้ม = suffix) · จุดเล็ก = ศัพท์ สีตามระดับ CEFR · แถบสีในฟอง = สัดส่วน CEFR

## โครงสร้าง

```
index.html            เว็บหลัก (โหลดข้อมูลจาก data/ ตอนเปิด)
standalone.html       เว็บแบบไฟล์เดียว ฝังข้อมูลไว้ในตัว (สร้างด้วย tools/build_standalone.py)
data/manifest.json    รายชื่อไฟล์ข้อมูลที่จะโหลด
data/words.txt        ข้อมูลศัพท์หลัก
tools/build_obsidian.py   สร้าง Obsidian vault จากข้อมูลชุดเดียวกัน
```

## วิธีขึ้นเว็บด้วย GitHub Pages (ทำบนไอแพดได้)

1. สร้าง repo ใหม่บน github.com (เช่นชื่อ `word-roots`) ตั้งเป็น Public
2. Add file → Upload files แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (รวมโฟลเดอร์ `data` และ `tools`)
3. Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / root → Save
4. รอ 1–2 นาที เปิด `https://<ชื่อผู้ใช้>.github.io/word-roots/`

หลังจากนั้นแก้ไฟล์ใน repo เว็บจะอัปเดตเอง ไม่ต้อง build อะไร

## วิธีเพิ่มศัพท์

เปิด `data/words.txt` บน GitHub กดไอคอนดินสอ แล้วเพิ่มบรรทัด หรือสร้างไฟล์ใหม่ใน `data/` (เช่น `data/oxford-5000.txt`) แล้วเพิ่มชื่อไฟล์ใน `data/manifest.json`:

```json
["words.txt", "oxford-5000.txt"]
```

รูปแบบ 1 บรรทัด = 1 รากหรือ affix:

```
ชนิด|รูปที่ใช้ (คั่นด้วย ,)|ความหมายไทย|ความหมายอังกฤษ|ศัพท์:ระดับ:คำแปล;ศัพท์:ระดับ:คำแปล;...
```

ตัวอย่าง

```
root|struct|สร้าง|build|structure:B1:โครงสร้าง;construct:B2:ก่อสร้าง;instruct:B2:สั่งสอน
prefix|re|อีกครั้ง/กลับ|again/back|return:A2:กลับ;repeat:A2:ทำซ้ำ
suffix|tion,sion|การ/ภาวะ|act/state|action:A2:การกระทำ;decision:B1:การตัดสินใจ
```

- ชนิดมี 3 แบบ: `root`, `prefix`, `suffix`
- ระดับ: `A1 A2 B1 B2 C1`
- บรรทัดที่ขึ้นต้นด้วย `#` เป็นคอมเมนต์
- ถ้ามีรากเดิมอยู่แล้ว (ชนิด + รูปแรกเหมือนกัน) ศัพท์ใหม่จะถูกรวมเข้ากลุ่มเดิมอัตโนมัติ ไม่ว่าจะอยู่คนละไฟล์
- ศัพท์ที่อยู่ได้หลายราก ให้ใส่ซ้ำในแต่ละรากได้เลย (เช่น `television` ทั้งใน `vis` และ `tele`) จะมีเส้นเชื่อมข้ามกลุ่ม

### ให้ AI ช่วยสร้างข้อมูล

ส่งข้อความนี้ให้ Claude พร้อมรายการศัพท์ของคุณ:

> แตกศัพท์ต่อไปนี้ตามรากศัพท์/prefix/suffix แล้วตอบเป็นรูปแบบบรรทัด `ชนิด|รูปที่ใช้|ความหมายไทย|ความหมายอังกฤษ|ศัพท์:ระดับ CEFR:คำแปลไทย;...` ตามตัวอย่างใน README

แล้วก๊อปผลไปวางในไฟล์ใน `data/`

## Obsidian

รัน `python3 tools/build_obsidian.py` บนคอมพิวเตอร์ (ต้องมี Python 3) จะได้โฟลเดอร์ `Word Roots` และไฟล์ zip พร้อมเปิดเป็น vault ถ้าอยู่บนไอแพดล้วน ๆ ให้ขอให้ Claude สร้าง vault ชุดใหม่จากไฟล์ข้อมูลของคุณ
